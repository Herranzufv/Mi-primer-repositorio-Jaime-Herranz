## 1. Estructura del Sitio
El sitio web cuenta con las siguientes secciones:
- **Home:** Página de bienvenida.
- **About:** Información personal.
- **Contact:** Formulario de contacto.
- **Topic:** Artículo sobre Ciberseguridad.
- **Degree:** Información del grado y asignatura de Fundamentos.
- **Net:** Enlaces a compañeros.

Se ha utilizado una hoja de estilos CSS en la carpeta `css/` y una carpeta `img/` para las imágenes.
